Hi, This repository is titled cree-syllabic-point-click-keyboard-javascript-html.

It is for typing Western Cree using Canadian Aboriginal Syllabics in a web browser.
The main benefit is that a person using it does not have to install software on their
computer as long as they have a web browser.

It does not support saving, or undo functionality. Users should save their work in
a different program for saving text.

You can use this application while being connected to the internet, by going to:
https://grassdewmorning.github.io/cree-syllabics-point-click-keyboard-javascript-html/CreeAlphabet.html

You can use this application without being connected to the internet. But first,
you will need to download the CreeAlphabet.html file from this repository, or the whole
repository.

If your computer is old (has an older operating system) or for some other reason
does not have the appropriate fonts installed, you might not see the syllabics
symbols correctly. Unfortunately, this is not part of the goals of the work in this repository to support
older computers or computers without appropriate fonts.

If you have any concerns or questions, feel free to email; no guaranteed responses though:
grassdewmorning@gmail.com



## Technical Notes
This software is written in HTML and Javascript programming languages, along with CSS.
It is all written within a single HTML file. This may be considered bad practice by some, but
this is done intentionally to make it easier for users to download the project and use it portably
from their USB drive or other storage device.

The style of Javascript I chose to use is not intended to be sophisticated, and is intended to be extra simple.
This is why it may seem very repetitive to expert programmers.

I am interested in making this work on older browsers, but for now, my main concern is creating better input methods,
for Cree and other languages.

This was created using public computers at universities, libraries, and also my own private computer. That is part of
the reason why it is not written using the usual Javascript web stack that requires installation.
